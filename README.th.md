# 💝 หน้าเว็บของขวัญวาเลนไทน์

🇬🇧 English: [README.md](README.md)

เซอร์ไพรส์วาเลนไทน์แบบ 3 มิติในหน้าเดียว กล่องของขวัญหมุนอยู่บนพื้นหลังสีมืด เปิดออกด้วยแอนิเมชันที่คุณเลือก ข้างในมีดอกไม้ 3 มิติวางอยู่บนโน้ตลายมือที่ถามว่า **"เป็นวาเลนไทน์ของเค้านะ?"** เวลาชี้ที่คำตอบจะมีเส้นดินสอวงรอบ กด **ไม่** แล้วปุ่มจะเล็กลง กด **ได้สิ** แล้วจะมีฉากฉลองตามด้วยสไลด์รูปของคุณ เพลงและเสียงเอฟเฟกต์สร้างจากตัวหน้าเว็บเอง หรือจะใส่เพลงของคุณเองก็ได้

---

## 🚀 วิธีที่ง่ายที่สุด: `builder.html`

ดับเบิลคลิก **`builder.html`** เพื่อเปิดในเบราว์เซอร์ ตั้งค่าได้ทุกอย่างในหน้านั้นโดยไม่ต้องเขียนโค้ด ปุ่ม **ไทย / EN** มุมขวาบนใช้เปลี่ยนภาษาของหน้าตั้งค่า

| หัวข้อ | ตั้งค่าอะไรได้บ้าง |
|---|---|
| 1. กล่องของขวัญ | สีกล่องและสีริบบิ้น/โบว์ (มีกล่อง 3 มิติหมุนให้ดูตัวอย่าง) |
| 2. วิธีเปิดกล่อง | แอนิเมชันเปิดกล่องแบบ 3 มิติ (ดูด้านล่าง) |
| 3. โน้ตและข้อความ | **ภาษาของคำแนะนำบนหน้าเว็บ** (English หรือ ไทย พร้อมข้อความตัวอย่างภาษานั้น) คำถาม ข้อความปุ่มตอบตกลง/ปฏิเสธ ข้อความที่ปุ่มปฏิเสธจะเปลี่ยนไป คำลงท้าย และข้อความหลังตอบตกลง |
| 4. ดอกไม้ในกล่อง | ลากดอกไม้ไปวางบนก้นกล่อง มี 5 ชนิด: **กุหลาบ ทิวลิป เดซี่ ทานตะวัน ซากุระ** คลิกที่ดอกเพื่อเปลี่ยนชนิด สี ขนาด ย้ายไว้บน/ล่าง คัดลอก หรือลบ มีปุ่มจัดเรียงด่วนให้ด้วย ดอกไม้วางทับกันได้ ดอกที่เพิ่มทีหลังจะพิงอยู่ด้านบนโดยไม่ทะลุกัน |
| 5. ก้นกล่อง | สิ่งที่วางรอบๆ โน้ต: **กลีบกุหลาบ หัวใจกระดาษ คอนเฟตติ กระดาษฝอย** หรือไม่มี เลือกสี ปริมาณ และสีพื้นกล่องได้ |
| 6. เพลงและเสียง | อัปโหลดเพลงครั้งเดียว แล้วเลือกรูปแบบการเล่นเพลง (ดูด้านล่าง) ปิดเสียงเอฟเฟกต์และปรับความดังได้ |
| 7. รูปภาพ | เลือกหรือลากรูปมาวาง ใส่คำบรรยายแต่ละรูป ปุ่ม ◀ ▶ ใช้เปลี่ยนลำดับ |

ปุ่มด้านล่าง:

- **👀 ดูตัวอย่าง** ลองเล่นได้ทันที เลือกดูขนาดจอคอมหรือมือถือ
- **⬇️ ดาวน์โหลด index.html** ได้ **ไฟล์เดียว** ที่รวมรูปและเพลงไว้ข้างในแล้ว ส่งไฟล์นี้หรืออัปขึ้นเว็บได้เลย (ดูด้านล่าง)
- **📂 เปิดไฟล์ที่เคยทำไว้** โหลด `index.html` ที่เคยดาวน์โหลดไว้ กลับมาแก้ต่อได้
- **↺ เริ่มใหม่** กลับไปใช้ค่าเริ่มต้น

หน้าตั้งค่าจะจำการตั้งค่าไว้ในเบราว์เซอร์นั้น แต่รูปและเพลงขนาดใหญ่อาจจำไม่หมด ให้เก็บไฟล์ `index.html` ที่ดาวน์โหลดไว้ แล้วเปิดด้วย **📂 เปิดไฟล์ที่เคยทำไว้** เมื่ออยากแก้ต่อ

### รูปแบบเพลง 3 แบบ

| แบบ | เกิดอะไรขึ้น |
|---|---|
| 🎼 **แบบง่าย** | เพลงเดียวทั้งหน้า: กล่องดนตรีในตัว เพลงของคุณ หรือไม่มีเพลง เริ่มเล่นตอนเปิดกล่อง |
| 💓 **เพลงเดียว ท่อนฮุกตอนตกลง** | เพลงเริ่มจาก **จุดเริ่มเพลง** ทันทีที่เปิดหน้าเว็บตอนกล่องลอยอยู่ และเล่นต่อระหว่างเปิดกล่อง พอเลื่อนเข้าไป **ถึงโน้ต** เพลงจะค่อยๆ เบาลงจน **หยุด** พอกด **ได้สิ** **ท่อนฮุก** จะขึ้นเต็มเสียงและเล่นต่อไป (วนกลับที่ท่อนฮุก) |
| 🎬 **เพลงแยกแต่ละช่วง** | เลือกเพลงช่วง **1. ก่อนเปิดกล่อง** **2. หลังเปิดกล่อง** และ **3. หลังตอบตกลง** จะเป็นไม่มีเพลง กล่องดนตรี เล่นเพลงเดิมต่อ หรือเพลงของคุณเริ่มจากจุดไหนก็ได้ ตอนเปลี่ยนช่วงเพลงจะค่อยๆ ผสานกันอย่างนุ่มนวล |

**การเลือกจุดเริ่มเพลง / ท่อนฮุก:** แต่ละเพลงจะแสดง **คลื่นเสียง** (ช่วงที่ดังจะสูงกว่า เลยหาท่อนฮุกได้ง่าย) คลิกเลือกตัวมาร์ก (**จุดเริ่มเพลง** หรือ **ท่อนฮุก ♥**) แล้วคลิกหรือลากบนคลื่นเสียงเพื่อวาง หรือพิมพ์เวลา (`1:23.5`) กด **▶** เพื่อฟังจากจุดนั้น

> ถ้ามีเพลงก่อนเปิดกล่อง หน้าเว็บจะลองเล่นเพลงทันทีถ้าเบราว์เซอร์อนุญาต แต่เบราว์เซอร์ส่วนใหญ่จะไม่ให้มีเสียงจนกว่าผู้เข้าชมจะแตะหน้าเว็บหนึ่งครั้ง ในกรณีนั้นจะมีหน้า **"แตะเพื่อเริ่ม"** ขึ้นมาก่อน แตะครั้งเดียวเพลงก็เริ่ม แก้ข้อความหน้านี้ได้ในหัวข้อ 3

### แอนิเมชันเปิดกล่อง 5 แบบ

| แบบ | เกิดอะไรขึ้น |
|---|---|
| 🔍 **เลื่อนเข้าไปดู** | แตะเพื่อเปิด แล้วเลื่อน ปัดขึ้น หรือถ่างนิ้ว เพื่อเข้าไปดูในกล่องเอง |
| 👆 **แตะหลายครั้ง** | แตะแต่ละครั้งกล่องจะเด้งสูงขึ้นพร้อมหัวใจกระจาย ครั้งสุดท้ายกล่องจะเปิดและกล้องพาเข้าไปเอง เลือกจำนวนครั้งได้ |
| ✨ **แตะครั้งเดียว** | แตะครั้งเดียว ฝาลอยออกแล้วกล้องพาเข้าไปเอง |
| 💗 **กดค้าง** | กดค้างที่กล่องจนหัวใจเต็ม กล่องจะสั่นแรงขึ้นแล้วเด้งเปิด เลือกจำนวนวินาทีได้ |
| 📦 **คลี่กล่อง** | แตะครั้งเดียว ผนังทั้งสี่ด้านล้มลงราบ แล้วกล้องมองลงไปข้างใน |

ทุกแบบสามารถเลื่อนขึ้น (หรือปัดลง) เพื่อถอยออกมา และเลื่อนลงเพื่อกลับเข้าไปได้

## ✏️ แก้เองในโค้ด (ไม่จำเป็น)

ทุกอย่างที่หน้าตั้งค่าตั้งได้ อยู่ในส่วนเดียวใกล้ๆ ต้น `<script>` ของ `index.html` กด **Ctrl + F** แล้วค้นหา:

```
SETTINGS: change everything here
```

อยู่ประมาณ **บรรทัดที่ 577** ภายใน `const CONFIG = { … }` ในไฟล์ `index.html` ตั้งต้น ทุกค่ามีคำอธิบายกำกับไว้

| ค่า | ใช้ทำอะไร |
|---|---|
| `lang` | `'en'` หรือ `'th'` ภาษาของคำแนะนำในหน้าเว็บ ("เลื่อนลงเพื่อดูใกล้ๆ", "แตะเพื่อเริ่ม"…) ภาษาไทยจะใช้ฟอนต์ที่รองรับภาษาไทย |
| `box.color`, `box.ribbon` | สีกล่องและสีริบบิ้น เช่น `'#3a7bd5'` |
| `reveal.mode` | `'scroll'` `'taps'` `'auto'` `'hold'` หรือ `'unfold'` |
| `reveal.taps` / `reveal.holdSeconds` | จำนวนครั้งที่ต้องแตะ (แบบ taps) และจำนวนวินาทีที่ต้องกดค้าง (แบบ hold) |
| `text.*` | ข้อความทั้งหมด ใช้ `<br>` เพื่อขึ้นบรรทัดใหม่ คำถามยาวๆ จะย่อให้พอดีโน้ตเอง |
| `flowers` | รายการแบบ `{ type: 'rose', color: '#e8335f', x: -60, y: -64, size: 40 }` ชนิดมี `rose` `tulip` `daisy` `sunflower` `sakura` ค่า `x`/`y` ตั้งแต่ -88 ถึง 88 (0,0 คือตรงกลาง) ดอกไม้จะไม่ทะลุผนังกล่องหรือทะลุกันเอง ดอกที่อยู่ท้ายรายการจะวางอยู่ด้านบน |
| `floor.fill` | `'petals'` `'hearts'` `'confetti'` `'shred'` (กระดาษฝอย) หรือ `'none'` สิ่งที่วางรอบๆ โน้ต |
| `floor.color`, `floor.amount` | สีของสิ่งที่วาง (คอนเฟตติจะคละสีเอง) และจำนวนชิ้น (0 – 200) |
| `floor.base` | สีพื้นกล่อง `''` = ใช้สีกล่องแบบเข้มขึ้น |
| `photos` | `{ src: 'photos/me.jpg', caption: '…' }` ชื่อไฟล์บนเว็บต้องตรงตัวพิมพ์เล็ก/ใหญ่ |
| `slideSeconds`, `photosDelay` | จังหวะเวลาของสไลด์รูป |
| `sound.plan` | `'simple'` `'hook'` หรือ `'stages'` (ดูรูปแบบเพลงด้านบน) |
| `sound.songs` | เพลงของคุณ: `{ name: 'เพลงของเรา', src: 'sounds/our-song.mp3' }` ตำแหน่งอื่นจะอ้างถึงเพลงเป็น `'song:0'` `'song:1'` … |
| `sound.music` | สำหรับ `'simple'`: `'builtin'` `'none'` หรือ `'song:0'` |
| `sound.hook` | สำหรับ `'hook'`: `song`, `softStart` และ `hook` (วินาที), `softVolume`, `beginAt` (`'start'` = ตอนเปิดหน้าเว็บ หรือ `'open'` = ตอนเปิดกล่อง), `quietAfter` (วินาทีหลังถึงโน้ตก่อนเริ่มเบาลง), `fadeTime` (วินาทีที่ค่อยๆ เบาลงจนเพลงหยุด) |
| `sound.stages` | สำหรับ `'stages'`: `before` `opened` `yes` แต่ละอันเป็น `{ music: …, start: วินาที }` ใส่ `music` เป็น `'continue'` เพื่อเล่นเพลงเดิมต่อได้ |
| `text.startHint` | ข้อความบนหน้า "แตะเพื่อเริ่ม" |
| `sound.effects` | `false` = ปิดเสียงป๊อป กระดิ่ง และดินสอ |
| `sound.files.open / reveal / hover / no / yes` | ใช้ไฟล์ mp3 ของคุณแทนเสียงเอฟเฟกต์แต่ละจังหวะ (`''` = ใช้เสียงในตัว) |

> ไฟล์ที่ดาวน์โหลดจากหน้าตั้งค่าจะมีส่วนนี้เหมือนกัน แต่ไม่มีคำอธิบาย และรูปกับเพลงจะเก็บเป็นข้อความ `data:` ยาวๆ แก้ไฟล์แบบนี้ผ่าน **📂 เปิดไฟล์ที่เคยทำไว้** ในหน้าตั้งค่าจะง่ายกว่า

### ปรับลึกขึ้น (โค้ด)

| อยากแก้ | ค้นหาใน `index.html` |
|---|---|
| สีแสงพื้นหลัง | `--bg1:` |
| วิธีสร้างดอกไม้แต่ละชนิดแบบ 3 มิติ | `const FLOWERS = {` |
| ทำนองเพลงกล่องดนตรี | `const chords =` (60 = โด กลาง; `const beat = 60 / 72` คือความเร็ว 72 จังหวะต่อนาที) |
| ความเร็วตอนเลื่อนซูม | `0.0011` |
| ฝากล่องลอยออกไปแบบไหน | `@keyframes lidAway` |
| อีโมจิที่โปรยหลังตอบตกลง | `const pieces = [` |

ถ้าแก้ **โค้ด** ของ `index.html` (ไม่ใช่แค่ค่าตั้ง) ให้รันคำสั่งนี้เพื่อให้หน้าตั้งค่าใช้เวอร์ชันใหม่:

```bash
python tools/make-builder.py
```

## 🌐 ส่งให้แฟน (อัปขึ้นเว็บด้วย GitHub Pages)

ส่งเป็น **ลิงก์** ดีที่สุด แฟนแค่แตะลิงก์ก็เปิดได้เลยทั้งมือถือและคอม (ถ้าส่งเป็นไฟล์ แอปแชทบนมือถือมักเปิดไฟล์ HTML ไม่ได้หรือเล่นไม่ครบ)

1. นำ `index.html` ที่ดาวน์โหลดจากหน้าตั้งค่ามาวางในโฟลเดอร์นี้ แทนที่ไฟล์เดิม
2. อัปขึ้น GitHub:
   ```bash
   git add .
   git commit -m "ของขวัญวาเลนไทน์"
   git push
   ```
3. บน GitHub เปิด repo → **Settings** → **Pages** → Branch **main**, **/ (root)** → **Save**
4. รอประมาณหนึ่งนาที จะได้ลิงก์: `https://mrdewdotcom.github.io/Valentine/` 💌

> ถ้าแก้ของขวัญทีหลัง ดาวน์โหลด `index.html` ใหม่ แทนที่ไฟล์เดิมแล้ว push อีกครั้ง ลิงก์เดิมจะอัปเดตเองในไม่กี่นาที
>
> GitHub Pages แบบฟรีต้องใช้ repo สาธารณะ คนที่รู้ลิงก์จะเห็นหน้าเว็บรวมถึงรูปด้วย และ `builder.html` ก็จะอยู่บนเว็บที่ `…/Valentine/builder.html` ถ้าอยากเป็นส่วนตัวขึ้น ให้สร้าง repo แยกชื่อเดายากที่มีแค่ `index.html` ของขวัญ หรือเก็บ `builder.html` ไว้ในเครื่องอย่างเดียว (`git rm --cached builder.html`)
>
> เบราว์เซอร์จะให้มีเสียงหลังจากแตะครั้งแรกเท่านั้น ถ้ามีเพลงก่อนเปิดกล่อง ผู้เข้าชมจะเห็นหน้า "แตะเพื่อเริ่ม" ก่อน
